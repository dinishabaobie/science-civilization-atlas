# 科学、技术与文明

一份以时间轴为骨架的个人读书笔记网站。内容融合四本科学类读书笔记，沿科学、技术、文明三条轨道整理九个时代、52 个节点，以及人物、条件、影响和治理张力。

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

## 验证

```bash
npm run lint
npm test
```

`npm test` 会完成生产构建，并检查时间轴节点、思想框架与设计契约是否进入服务端输出。

## 内容边界

这是个人读书笔记母稿的互动阅读版本，不代替原书、一手资料或更新研究。时间轴中的人物以具体贡献和共同体关系出现，不采用单一英雄叙事。
