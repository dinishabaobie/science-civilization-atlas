# 科学、技术与文明

一份以时间轴为骨架的个人读书笔记网站。内容融合四本科学类读书笔记与结构重排母稿，沿科学、技术、文明三条轨道整理九个时代、53 个节点，并补入三个概念、两种燃料、七道闸门、四条主线、八次耦合、七条规律、技术十六问与六项批判。

## 在线访问

- [GitHub Pages 正式站点](https://dinishabaobie.github.io/science-civilization-atlas/)

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

## 验证

```bash
npm run lint
npm test
npm run build:pages
```

`npm test` 会完成生产构建，并检查时间轴节点、思想框架与设计契约是否进入服务端输出。
`npm run build:pages` 会在 `out/` 目录生成供 GitHub Pages 使用的静态版本。

## 内容边界

这是个人读书笔记母稿的互动阅读版本，不代替原书、一手资料或更新研究。时间轴中的人物以具体贡献和共同体关系出现，不采用单一英雄叙事。
